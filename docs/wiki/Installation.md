# Installation

## Windows

Use `AutoKeyPresser-Setup.exe` for a normal installation, or extract
`AutoKeyPresser-Portable.zip` and run `AutoKeyPresser.exe` without installing.

## Linux

Use the `.deb` package on Debian-based distributions, or extract the portable
tarball. Linux input automation requires an X11 session.

## macOS

Open the `.dmg` and move AutoKeyPresser to Applications. Grant Accessibility
and Input Monitoring permissions under System Settings > Privacy & Security.
