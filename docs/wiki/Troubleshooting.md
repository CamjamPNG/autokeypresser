# Troubleshooting

## Global hotkey does not work

Check that the operating system has granted input permissions. On Linux, use
an X11 session rather than Wayland.

## A macro is rejected

The file may be corrupted, modified, or from an unsupported future format.
Export it again from AutoKeyPresser and retry.

## The target application freezes

Increase the interval, disable random timing, or press F12.
