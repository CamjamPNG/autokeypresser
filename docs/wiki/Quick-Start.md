# Quick Start

1. Set the interval in hours, minutes, seconds, and milliseconds.
2. Choose Mouse or Keyboard under Click options.
3. Choose the repeat count or Repeat until stopped.
4. Press **Start** or the configured global hotkey.
5. Press the same hotkey or **F12** to stop.

Use **Pick location** for a fixed mouse coordinate. Use the **Macros (.akp)**
panel to record and replay a real keyboard/mouse interaction.
