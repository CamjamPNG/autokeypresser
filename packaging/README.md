# Package Manager Files

These are submission-ready starting points for package managers. Replace
`REPLACE_WITH_RELEASE_SHA256` with the checksum of the matching release asset
before submitting to the package repository.

- `winget/`: manifests for `microsoft/winget-pkgs`
- `choco/`: Chocolatey package files
- `scoop/`: Scoop bucket manifest
- `homebrew/`: Homebrew cask
- `aur/`: Arch User Repository PKGBUILD
